# Treino Simples

Aplicativo web de treinamento personalizado adaptativo. Funciona offline, sem servidor, sem banco de dados.

## Características

- **Personalização semântica**: as cores do app nascem do seu texto e das suas escolhas — não de categorias fixas
- **Onze objetivos**: força, desempenho atlético, massa muscular, emagrecimento, condicionamento, corrida, TAF específico, estética, operacional, mobilidade e saúde, com um objetivo principal guiando a estrutura da semana
- **Cobertura de sete dias**: todo dia tem um plano — aquecimento e treino, ou descanso ativo
- **Periodização de 4 semanas**: BASE → CARGA → CHOQUE → DESCARGA
- **Motor adaptativo**: prontidão diária (sono, dor, estresse, energia) e feedback pós-treino ajustam a sugestão de carga
- **Zonas de corrida reais**: calcula VDOT a partir do seu tempo numa distância
- **Gráficos**: volume semanal, curva de carga por exercício, radar de desempenho
- **Editor de treino**: ajuste pontual de séries e repetições, válido só para o dia
- **Múltiplos perfis**: histórico, cargas e corridas isolados por pessoa
- **Backup manual**: exporta e importa uma cópia em JSON

## Como usar

Abra o link do GitHub Pages, complete a entrevista de 5 etapas (identificação, objetivos, restrições, disponibilidade, tema) e comece a treinar.

## Tecnologia

HTML5, CSS3 e JavaScript puro — nenhuma dependência externa, um único arquivo, funciona completamente offline.

## Dados

Tudo fica salvo no navegador do aparelho. Use "Exportar cópia" na aba Perfis para fazer backup ou levar seus dados para outro aparelho.
